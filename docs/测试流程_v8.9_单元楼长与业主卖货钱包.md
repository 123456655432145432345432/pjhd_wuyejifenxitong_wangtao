# 测试流程 — v8.9 单元楼长 & 业主卖货钱包

> **版本**：2026-10-04 · 对照 `API接口文档_v8.9.md` §99 +《前端交付说明_单元楼长与业主卖货钱包(1).html》
> **被测前端**：邻里商城服务管理端（本仓库） · 分支 `feature/wangao`
> **核心口径（务必先读）**：楼长是「**住户 + 楼长**」复合身份——住户 `role` **始终是 `resident`**，楼长身份由 `building_leaders` 表判定，前端凭 `GET /auth/profile` 的 `isBuildingLeader` / `buildingLeaderId` 识别。**任何"楼长登录后 role 变成 building_leader"的现象都是 Bug。**

## 2. 场景 A · 管理端楼长管理（property_admin / platform_admin）

> 入口：左侧菜单「单元楼长」

| # | 步骤 | 期望结果 | 记录 |
|---|------|----------|------|
| A1 | 打开「单元楼长」 | 列表分页加载；列含 住户/手机号/小区/楼栋/比例/累计分成/状态/任命时间 | ⬜ |
| A2 | 指定楼长：搜索选 R1，**不填**小区/楼栋，比例留默认 0.1，备注「1号楼楼长」 | 200；小区/楼栋自动取 R1 所属；列表新增记录，状态 active | ⬜ |
| A3 | **核心校验**：用 R1 账号查询（或看住户管理详情） | R1 的 `role` **仍为 `resident`**；R1 的住户功能（社区论坛、我的店铺）**不受影响** | ⬜ |
| A4 | 再指定 R3（同小区同楼栋 1号楼）为楼长 | `400 / 10002`（该楼栋已有 active 楼长） | ⬜ |
| A5 | 再次指定 R1（已在 1 号楼任楼长） | `400 / 10002`（该住户已是 active 楼长） | ⬜ |
| A6 | 指定 R2 到 2 号楼（不填楼栋，且临时用 R2 无楼栋账号或手填楼栋） | 200；1 号楼/2 号楼可各自有楼长（互不冲突） | ⬜ |
| A7 | 比例边界：填 `0`、`1.5`、`-0.1`、`abc` | 前端拦截「须大于 0 且不超过 1」；后端 `10002` 兜底 | ⬜ |
| A8 | 比例边界：填 `1` | 允许（区间为 (0,1]） | ⬜ |
| A9 | 编辑：比例改 0.12 + 改备注 + 状态改 inactive → 再改回 active | 每步 200；列表即时反映 | ⬜ |
| A10 | 筛选：关键字（R1 姓名/手机号）、状态、楼栋、小区 | 各筛选条件生效；清空可恢复全量 | ⬜ |
| A11 | 平台管理员视角：用 `propertyCompanyId` 切到 B 物业查列表 | 可跨物业；物业管理员用同参数**只能看到自己物业** | ⬜ |
| A12 | 权限：物业**操作员**（property_operator）进入该页 | 菜单可见（与现有其他组织类页面一致）；能否操作由后端校验 | ⬜ |

## 3. 场景 B · 分成链路（关键：快照 + 定向扣除）

> 入口：管理端「分成明细」「分成统计」

| # | 步骤 | 期望结果 | 记录 |
|---|------|----------|------|
| B1 | 用 **1 号楼住户** 下单 → 完成收货（确认收货后才结算） | 分成明细新增该订单 | ⬜ |
| B2 | 在「分成明细」查看该单 | **新增「楼长」列有值**；金额 = 该单 `property_share` × 楼长比例（下单时快照） | ⬜ |
| B3 | 对比同单「物业」列 | 金额 = 原物业分成 **−** 楼长分成（总额守恒；统筹/板块/个体分项**不受影响**） | ⬜ |
| B4 | 「分成统计」页 | 出现「楼长分成」卡片，数值 = 明细中楼长分项求和 | ⬜ |
| B5 | **快照不回改**：把楼长比例从 0.1 改成 0.2 | B1 那笔旧订单的楼长分成**不变** | ⬜ |
| B6 | **撤销后不再产生**：撤销 1 号楼楼长 → 1 号楼再下一单并完成 | 新订单**无**楼长分成（物业列恢复全额） | ⬜ |
| B7 | 退款冲账：对 B1 订单走退款 | 分成明细出现负数冲账行，楼长分项同步冲账 | ⬜ |

## 8. 错误码速查

| 错误码 | HTTP | 含义 | 前端表现 |
|--------|------|------|----------|
| `91004` | 404 | 楼长不存在 / 当前用户不是楼长 | 楼长页显示「当前账号不是启用中的单元楼长」 |
| `10001` | 400 | 参数缺失（住户未关联小区/楼栋且未指定） | 表单错误提示 |
| `10002` | 400 | 参数不合法（比例越界 / status 非法 / 楼栋已有 active 楼长 / 住户已是 active 楼长） | 表单错误提示 |
| `30001` | 404 | 业主不存在 | 提示 |
| `97001` | 404 | 物业公司不存在 | 提示 |
| `94003` | 400 | 可提现余额不足 | 提现弹窗内提示 |
| `94005` | 400 | 提现已被冻结 | 提现弹窗内提示 |
| `20004` | 403 | 权限不足（楼长操作他人 / 角色不符） | 提示，不跳登录 |

## 9. 验收通过标准

1. 场景 A–E 全部 ⬜ → ✅，F 回归无异常
2. **口径零违例**：全程无"住户 role 被改写"、无"楼长按 role 判定"
3. 分成守恒：`物业列 + 楼长分项 = 原物业分成`；统筹/板块/个体分项不变
4. **快照不回改**：改比例/撤销楼长后，历史订单分成分文不动
5. 前端控制台无报错；`vue-tsc` 类型检查 0 错误（本仓库已通过）
