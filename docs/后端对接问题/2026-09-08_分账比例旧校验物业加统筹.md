# 分账比例校验仍用旧规则「物业+统筹=100%」

> **状态**：后端已修（API v8.2），待测服验收  
> **日期**：2026-09-08  
> **说明**：后端已删除「物业+统筹=1」「板块+个体≤1」旧校验，统一 **97006** 三档合计；`platformShareRate` 纳入 config。前端已去掉 `legacyTwoTier` 兼容分支。

## 现象

平台超管配置平台盘三档后保存失败。前端提示：

> 分账保存失败：后端仍要求「物业+统筹=100%」。

界面示例（三档合计已 100%）：

| 档位 | 界面值 | 提交绝对值（约） |
|------|--------|------------------|
| 我们公司 `platformShareRate` | 10%（只读，平台分成配置） | 0.10 |
| 物业 `propertyShareRate` | 59.8% | 0.598 |
| 管理盘 `coordinatorShareRate` | 30.2% | 0.302 |
| **合计** | **100.0%** | **1.000** |

后端仍按旧规则校验：`propertyShareRate + coordinatorShareRate === 1`  
→ `0.598 + 0.302 = 0.900 ≠ 1` → **400**，文案类似「物业分成比例与统筹分成比例之和须等于1」。

## 复现

1. 超管 `13800138000` / `admin123456` →「参数配置」→「分账」  
2. 确认「我们公司」有只读占比（如 10%）  
3. 将「物业 + 管理盘」调成与「我们公司」互补（合计 100%），例如 59.8 + 30.2  
4. 点「保存全局设置」→ 失败  

（若先把物业+管理盘改成合计 100%、忽略我们公司，旧校验可能通过，但会与文档三档模型及真实分账口径冲突。）

## 期望契约（API v8.1）

商品平台盘**一级三档**合计必须为 100%：

```text
platformShareRate + propertyShareRate + coordinatorShareRate = 1.0000
```

- 错误码：**`97006`**  
- 文案语义：商品平台盘一级比例合计必须为 100%  
- **禁止**再校验 `propertyShareRate + coordinatorShareRate = 1`

分账含义（文档）：

```text
平台分享 = 平台盘 × platformShareRate
物业分享 = 平台盘 × propertyShareRate
管理盘   = 平台盘 × coordinatorShareRate
```

管理盘内部再按级联拆分统筹 / 板块 / 个体（`sectorLeaderRate`、`individualLeaderRate` 为级联系数，**不得**要求二者之和 ≤ 1）。

`platformShareRate`（我们公司）可由「平台分成配置」写入；物业配置接口写 `propertyShareRate` / `coordinatorShareRate` 时，校验必须把已落库的 `platformShareRate` 一并计入三档合计。

## 当前缺口

测服仍保留历史校验：

| 规则 | 文档 v8.1 | 测服现状 |
|------|-----------|----------|
| 三档合计 = 1（含我们公司） | ✅ `97006` | ❌ 未按此校验（或未生效） |
| 两档合计 = 1（物业+统筹） | ❌ 已废弃 | ✅ 仍拦截 |

## 建议后端改动

1. **删除**（或关闭）「物业分成 + 统筹分成之和须等于 1」校验。  
2. **启用** `97006`：保存 config 时校验  
   `platformShareRate + propertyShareRate + coordinatorShareRate` 在容差内等于 `1.0000`  
   （`platformShareRate` 取当前物业已配置值；本次 body 若带则用 body）。  
3. 确认积分分成 / `PUT /property-companies/{id}` 等同路径**不要**再套用旧两档校验。  
4. （顺带）若仍有「板块+个体之和不能超过 1」：级联字段默认常为 `0.6` + `0.5`，相加会误伤；应删除该相加校验。

## 验收用例

| 请求体要点 | 期望 |

| `platformShareRate=0.10`（已存）, body `propertyShareRate=0.598`, `coordinatorShareRate=0.302` | **200**，三档合计 1 |
| `property=0.6`, `coordinator=0.4` 且已存 `platform=0.10`（合计 1.1） | **400 / 97006** |
| 仅 `property+coordinator=1` 但未含 platform（例如 0.6+0.4，platform=0.1 → 合计 1.1） | **400 / 97006**（勿再放行旧两档） |
