## 约定

1. **一个问题一份文档**，不要往旧文档里堆多个无关主题。
2. 文件名：`YYYY-MM-DD_简短主题.md`（例：`2026-09-06_新建物业公司.md`）。
3. 文档至少包含：现象、复现、期望契约、当前缺口、建议后端改动、前端已做/未做。
4. 状态可在文首标注：`待后端` / `联调中` / `已关闭`。
