# 分销商品缺少修改/删除接口

> **状态**：待后端  
> **日期**：2026-09-07  
> **对照**：API v8.1 §60.12 / §63（仅 list / create / billing-cycle）  
> **前端入口**：业主商户 → 分销商品

## 现象

列表操作列只有「设置周期」。管理端无法改名称/价格/库存/封面，也无法删除。

## 现状契约

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/admin/distributor-products` | 列表 |
| POST | `/admin/distributor-products` | 新建 |
| PUT | `/admin/distributor-products/{id}/billing-cycle` | 仅收费周期 |

## 期望

1. `PUT /admin/distributor-products/{id}`：改 name / coverUrl / wholesalePrice / suggestedRetailPrice / stock / description 等  
2. `DELETE /admin/distributor-products/{id}`：删除或下架（请明确硬删还是 `status=inactive`）  
3. 文档与 Roles（`property_admin` / `platform_admin`）同步  

前端已在页头标明「改内容/删除接口未开放」；接口就绪后即可接编辑弹窗与删除按钮。
