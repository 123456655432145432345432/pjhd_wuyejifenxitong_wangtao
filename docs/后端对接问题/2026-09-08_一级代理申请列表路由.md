# 一级代理申请列表 400/404

> **状态**：后端已修（API v8.2），待测服验收  
> **日期**：2026-09-08  
> **入口**：一级代理 → 申请审核  
> **文档**：§37 GET `/admin/individual-leaders/applications`

## 现象

1. `GET /admin/individual-leaders/applications?auditStatus=pending&...` → **400**（多为把 `applications` 当成 `{id}`，报 ID 格式不正确）  
2. 前端兼容路径 `GET /admin/individual-leader-applications` → **404**（未实现）

## 期望

1. **单独注册** `GET /admin/individual-leaders/applications`，且在 Spring 中**优先于** `GET /admin/individual-leaders/{id}`。  
2. 配套 `POST /admin/individual-leaders/applications/{applicationId}/audit` 同样避免被 `{id}` 吃掉。  
3. Query：`page`/`pageSize`/`auditStatus`/`sector`/`keyword`/`propertyCompanyId`（与文档一致）。

## 前端

- 默认进「已任命」；申请 Tab 失败时提示路由问题。  
- 日常可用「直接任命」绕过住户申请流。
