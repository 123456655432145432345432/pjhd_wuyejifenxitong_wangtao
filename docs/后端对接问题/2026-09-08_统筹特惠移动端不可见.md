# 统筹特惠推送：管理端已创建，移动端（住户）看不到

> **状态**：后端已修（API v8.3），待测服验收  
> **日期**：2026-09-08  
> **入口**：统筹账号 → 特惠推送 → 新建  
> **接口**：`POST /special-offers`（写）、`GET /special-offers` / `/special-offers/my`（住户读）  
> **对照**：API v8.3 §25；修复说明《2026-09-08_板块与特惠_后端修复说明》§2  
> **住户端联调说明**：[../住户端如何看到统筹特惠_对照API_v8.3.md](../住户端如何看到统筹特惠_对照API_v8.3.md)

## 根因（后端已确认）

此前 `GET /special-offers` **未对 `resident` 放行**，住户 Token 直接 **403**；并非仅「状态写成草稿」。

## 后端已实现

| 项 | 说明 |
|----|------|
| 住户可读 | `GET /special-offers`、`/special-offers/my`、`/{id}` 对 `resident` 放行 |
| 可见规则 | 仅 `published` + 时间窗 + 本物业 + targetType；**不按 publisherRole 过滤** |
| 发布/下架 | `POST /{id}/publish`、`POST /{id}/unpublish` |
| 状态别名 | `active` /「待发布」→ `published`（无独立待发布态） |

## 管理端已对接（本仓库）

| 项 | 说明 |
|----|------|
| 默认状态 | 新建默认 `published` |
| 发布/下架 | 列表「立即发布」「下架」 |
| 枚举 | 去掉「待发布=`active`」选项；别名归一为 `published` |
| 文案 | 草稿旁提示住户端不可见 |

## 测服验收

1. 部署 v8.3 + 执行板块/特惠 SQL  
2. 统筹创建已发布特惠 → 同物业住户 Token 调 `GET /special-offers` 含该 id  
3. 草稿 / 下架 → 住户列表无该条
