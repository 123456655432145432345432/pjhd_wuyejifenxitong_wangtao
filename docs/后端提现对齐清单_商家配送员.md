# 商家 / 配送员提现 — 前后端对齐清单

> 前端已于提现页增加：可提现 / 处理中 / 已提现 / 阻止状态展示，以及申请前本地校验。  
> **余额真相与超提拦截必须以服务端为准**；前端校验只是体验兜底。勿本地累加余额。

## 对接接口

| 场景 | 接口 | 关键字段 |
|------|------|----------|
| 商家查可提现 | `GET /merchants/my` | `withdrawableAmount`、`totalRevenue`、`totalWithdrawn`、`withdrawalBlocked` |
| 商家提现 | `POST /merchant/withdrawals` | body `{ "amount": number }` |
| 商家提现记录 | `GET /merchant/withdrawals` | `status`: pending/approved/rejected/completed |
| 配送查可提现 | `GET /courier-managers/my` | 同上钱包字段（负责人汇总 / 普通配送员看本人；`role=courier` 即可） |
| 配送提现 | `POST /courier-managers/my/withdrawals` | `{ "amount": number }` |
| 配送提现记录 | `GET /courier-managers/my/withdrawals` | 同上 |
| 单笔预计收入 | 配送列表/完成接口 | `courierEarning`（**B方案**：= 配送费 − 我们公司抽成，无保底；与分账 `courierShare` 同一笔；展示用，可提现以钱包接口为准） |

## 入账触发（刷新时机）

| 角色 | 触发 | 前端动作 |
|------|------|----------|
| 配送员 | `POST /deliveries/{id}/complete` 成功 | **立刻** `GET /courier-managers/my` |
| 商家 | 订单变为 `completed`（确认收货或改状态） | **立刻** `GET /merchants/my` |

注意：只完成配送、订单仍是 `delivering` → **商家**可提现不应变。

## 错误码

| code | 含义 |
|------|------|
| 94003 | 可提现余额不足 |
| 94005 | 已被阻止提现 |

## 提现状态机对钱包的影响

| 动作 | 钱包 |
|------|------|
| 申请成功 | 可提现减少（或冻结增加） |
| 审核拒绝 | 退回可提现 |
| 完成 `completed` | 冻结转出；`totalWithdrawn` 增加 |

## 前端自测断言

1. 配送完成前 `withdrawable = A`；完成后 `withdrawable ≈ A + courierEarning`（A方案下 `courierEarning` 不应再是固定 0.35/单）
2. 商家：订单 `completed` 前 `withdrawable = B`；完成后 `withdrawable ≈ B + order.totalAmount`（需扣已占用提现）
3. 超额申请 → 94003；`withdrawalBlocked=true` → 金额为 0 且不可提
4. 账号：商家须为该订单店主；配送用完成配送的那个 courier 账号查余额

## 常见对不齐

| 现象 | 先查 |
|------|------|
| 配送完成可提现仍为 0 | 是否调了 complete；响应 status 是否 delivered；是否刷新了 `/courier-managers/my` |
| 商家完成订单仍为 0 | `orderStatus` 是否真是 completed；是否串了别的商家账号 |
| 提现按钮一直灰 | 是否误读旧「须为负责人」逻辑；或 `withdrawalBlocked` |
| 数字对不上 | 是否用本地加减，而不是以接口返回为准 |

## 前端已做

- 商家/配送提现页：钱包卡片 + `amount ≤ withdrawableAmount` + `withdrawalBlocked` 禁用
- 配送完成成功 → 立刻拉 `/courier-managers/my` 展示最新可提现
- 商家订单确认完成 → 立刻拉 `/merchants/my`
- 列表 `courierEarning` 展示为「预计收入」；可提现以 `withdrawableAmount` 为准
- 已去掉「订单完成后才入账 / 须为快递负责人」旧文案
