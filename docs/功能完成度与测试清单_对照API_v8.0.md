## F. 建议测试顺序（最短路径）

1. **超管** `13800138000`：平台分成 10% → 参数三档 100% → 导航四套各加一条 → 物业银行卡 points/reward → 归属模式  
2. **领导** `13900000020`：大盘分成条、操作员、踢商家、推荐商家  
3. **操作员** `13900000021`：发放审批、定向推送带商品 ID、楼栋审批、业主商户审核  
4. **统筹→板块→个体**：建链 → 商家入驻审 → 分成审批 → 提现  
5. **快递负责人**：建负责人 → 加快递员 → 设 shareRate → 配送单  
6. **分销**：管理端上架 stock=1 商品 → 业主商户拿货 → 第二人应失败 → 取消释放
