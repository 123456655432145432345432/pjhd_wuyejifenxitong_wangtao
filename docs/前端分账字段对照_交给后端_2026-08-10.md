## 0. 一句话模型

```
订单实付 totalAmount = 商品价 productAmount + 配送费 deliveryFee

├─【商品价线】
│   ├─ 商家 ≈ productAmount × (1 − commissionRate)
│   └─ 平台盘 distributableAmount ≈ productAmount × commissionRate − 积分/币成本
│         ├─ 我们公司  platformShareRate          （三档之一，默认 10%）
│         ├─ 物业      propertyShareRate          （三档之一，默认 60%）
│         └─ 管理盘    coordinatorShareRate       （三档之一，默认 30%）
│               ├─ 统筹本人 = 管理盘 × (1 − sectorLeaderRate)
│               ├─ 板块    = 管理盘 × sectorLeaderRate × (1 − individualLeaderRate)
│               └─ 个体    = 管理盘 × sectorLeaderRate × individualLeaderRate
│
└─【配送费线 · 独立】
    ├─ 我们公司  platformDeliveryShare = deliveryFee × platformDeliveryShareRate
    └─ 配送员    courierShare / courierEarning = deliveryFee − platformDeliveryShare
                 （无保底；不进平台盘；禁止平台盘×15%）
```

三档校验：`platformShareRate + propertyShareRate + coordinatorShareRate ≈ 1`  
管理内默认 4:3:3：`sectorLeaderRate=0.6`，`individualLeaderRate=0.5`

## 1. 页面与接口

| 页面 | 主要接口 | 谁可写 |
|---|---|---|
| 平台分成配置 | `GET/PUT /admin/platform-share-rates` | 仅平台管理员 |
| 参数配置 · 分账 | `PUT /admin/property-companies/{id}/config`（及 config 回显） | 分成字段仅平台管理员 |

两页都读同一套物业分成比例；**「我们公司 / 配送费抽成 / 提现手续费分成」只在平台分成配置可改**，参数页只读。

## 2. 平台分成配置 · 字段对照

截图示例：万达花园；我们公司 10%；配送费抽成 0%；提现手续费分成 100%。

| 界面文案 | 截图示例值 | API 字段 | 写入本页？ | 含义 |
|---|---|---|---|---|
| 我们公司（平台盘内） | 10% | `platformShareRate` = `0.10` | ✅ 可写 | 平台盘三档之一 |
| 平台配送费抽成（我们公司） | 0% | `platformDeliveryShareRate` = `0` | ✅ 可写 | 从**配送费**抽成；余额归配送员 |
| 提现手续费分成 | 100% | `platformWithdrawalFeeShareRate` = `1` | ✅ 可写 | 独立链路，不进订单两层分账 |
| 物业（只读展示） | 60% | `propertyShareRate` | ❌ 只读 | 参数页改 |
| 管理/统筹盘（只读展示） | 30% | `coordinatorShareRate` | ❌ 只读 | 管理盘整体 |
| 板块负责人（抽管理盘） | 60% | `sectorLeaderRate` | ❌ 只读 | **级联**：占管理盘比例 |
| 个体负责人（抽板块） | 50% | `individualLeaderRate` | ❌ 只读 | **级联**：占「板块毛额」比例 |
| 配送 · 公司 / 骑手 | 0% / 100% | 由 `platformDeliveryShareRate` 推导 | — | 展示用 |


**不在本页提交**：`propertyShareRate` / `coordinatorShareRate` / `sectorLeaderRate` / `individualLeaderRate`。

## 3. 参数配置 · 分账字段对照

截图示例：平台盘 10/60/30；管理内展示 40/30/30；配送抽成只读 0%；重量加价 0.04。

### 3.1 平台盘三档

| 界面文案 | 截图值 | 前端变量 | API 字段 | 写入本页？ |
|---|---|---|---|---|
| 我们公司（只读） | 10% | `platformSharePercent` | `platformShareRate` | ❌ 只读 |
| 物业 | 60% | `propertySharePercent` | `propertyShareRate` | ✅ |
| 管理 / 统筹盘 | 30% | `coordinatorSharePercent` | `coordinatorShareRate` | ✅ |

校验：`platformShareRate + propertyShareRate + coordinatorShareRate ≈ 1`

### 3.2 管理盘内拆分（界面平铺 4:3:3 → 落库级联）

| 界面文案（占管理盘） | 截图值 | 前端展示变量 | 落库字段 | 4:3:3 时写入值 |
|---|---|---|---|---|
| 统筹 | 40% | `managementSplit.coordinatorPercent` | 无独立字段（剩余） | `1 − sectorLeaderRate = 0.40` |
| 板块负责人 | 30% | `managementSplit.sectorPercent` | → `sectorLeaderRate` | `0.60` |
| 个体负责人 | 30% | `managementSplit.individualPercent` | → `individualLeaderRate` | `0.50` |

**换算公式（前端保存前执行）：**

```
sectorLeaderRate     = (板块% + 个体%) / 100
individualLeaderRate = 个体% / (板块% + 个体%)     // 分母为 0 则为 0
```

截图 40/30/30 → `sectorLeaderRate=0.60`，`individualLeaderRate=0.50`。

**级联拆钱（管理盘金额 M）：**

```
板块毛额     = M × sectorLeaderRate
个体         = 板块毛额 × individualLeaderRate
板块实得     = 板块毛额 − 个体
统筹实得     = M − 板块毛额
```

### 3.3 配送费区（本页）

| 界面文案 | 截图值 | 前端变量 | API 字段 | 写入本页？ |
|---|---|---|---|---|
| 我们公司抽成（只读） | 0% | `platformDeliverySharePercent` | `platformDeliveryShareRate` | ❌ |
| 配送员所得（只读） | 100% | `100 − 抽成` | 无 | — |
| 按重量加价 | 0.04 | `deliveryPerKgFee` | `deliveryPerKgFee` | ✅ |

### 3.4 参考比例（不进主链，折叠区）

| 界面 | API 字段 | 说明 |
|---|---|---|
| 区域负责人 | `regionalLeaderRate` | 不进主分成链 |
| 项目负责人 | `projectLeaderRate` | 不进主分成链 |

## 4. 校验规则对照（请后端按此改）

| # | 规则 | 正确？ | 说明 |
|---|---|---|---|
| 1 | `platformShareRate + propertyShareRate + coordinatorShareRate ≈ 1` | ✅ 要 | B 方案平台盘三档 |
| 2 | 再加「快递员/快递档」凑四档 = 1 | ❌ 不要 | 已废止；会导致 100%+15%=115% |
| 3 | `sectorLeaderRate + individualLeaderRate ≤ 1` | ❌ 不要 | **当前误报来源**；二者不同层 |
| 4 | `0 ≤ sectorLeaderRate ≤ 1` 且 `0 ≤ individualLeaderRate ≤ 1` | ✅ 要 | 各自合法即可 |
| 5 | 配送员收入来自配送费，不进平台盘求和 | ✅ 要 | `platformDeliveryShareRate` 独立 |
| 6 | 开关 `courierShareFromDeliveryFee=true` 时走 B | ✅ 要 | 两页/两 Service 行为须一致 |

### 关于当前红字

1. ~~「平台服务费+…+快递四档须等于1 / 当前115%」~~  
   → 旧 A 方案；应改为只验三档。

2. **「板块与个体负责人比例之和不能超过1」**  
   → 前端提交的是级联值 `0.60` + `0.50`，**不能相加**。  
   → 请删除或改为：各自 ∈ [0,1]；可选校验「展示换算后的管理内三档之和 ≈ 1」。
