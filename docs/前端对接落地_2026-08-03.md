# 前端管理端对接落地说明（2026-08-03）

> **依据**：  
> - 《前后端对接交付_2026-08-03》  
> - 《API接口文档_v4.6》（含 v4.8 修订）

## 已落地（契约就绪）

| 事项 | 前端改动要点 |
|------|----------------|
| 家庭/个人积分分栏 | `ResidentItem.familyPointBalance`；`Points.vue` / `Resident.vue` 双栏展示 |
| 账期徽章 + 楼层排序 | `floor` / `arrearsPeriodStart` / `arrearsPeriodEnd`；`sort=+building,+floor,+unit,+room` |
| 统筹/板块提现 | `CoordinatorWithdrawals` / `SectorLeaderWithdrawals` + 菜单；`withdrawableAmount` |
| 提现审批看板 | `MerchantWithdrawalApproval` 顶部 summary 卡（`GET /admin/merchant-withdrawals/summary`） |
| 板块挂区域负责人 | `sectorLeaderMenus` → `regional-leaders`；`RegionalLeaders` 对板块角色锁定本人 |
| 社区论坛治理 | `CommunityForum.vue`：帖子列表/删帖/删评论、举报列表/处理 |
| 服务询价 | 保留表单报价，文案标明为正式方案 |
| 假数据清理 | 物业币「已消费」缺字段时显示「—」，不再 ×0.25 |

## 明确不做（待产品拍板 / 非管理端）

- 服务询价改聊天发价  
- 区域负责人提现  
- 区域/项目独立登录门户  
- 技工对齐全套商家能力  
- **居民端**社区论坛发帖/点赞/评论（属 C 端）
