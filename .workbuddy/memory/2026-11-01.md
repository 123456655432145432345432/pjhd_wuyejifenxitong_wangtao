- 背景：v8.13+ 把楼长 / 物业经理 / 统筹 / 板块 / 个体 / 活动组长 / 业主商家 / 分销商全部改为 `role=resident` + 布尔标签，`AppHeader` 右上角只读 `role` 字段，导致这批人一律显示「住户」。
