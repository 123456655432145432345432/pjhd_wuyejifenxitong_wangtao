# 2026-10-14

## v8.11 前端对接（一级代理件数制 + 物业经理）

依据《前端交付说明_v8.11》与《API接口文档_v8.11.md》完成管理端/住户端四模块对接。类型检查(vue-tsc)与生产构建(vite build)均通过。

### A. 物业经理管理页（新增）
- 新增 `src/views/admin/PropertyManagers.vue`：列表/关键字筛选(姓名手机)/状态筛选/平台管理员物业筛选/分页；
  指派（ResidentSearchSelect 选住户）、编辑抽成比例(0≤rate<1)与状态、停用。
- 错误码映射：91006(同物业已有在职经理)、91008(不可改自己比例)、30001(住户不存在)、20004(跨物业)。
- 路由：`/admin/property-managers`，roles=ADMIN_ROLE_LIST；菜单 adminMenus 增「物业经理」。

### B. 一级代理商家（商家 is_distributor 标志）
- `src/views/admin/ResidentMerchants.vue` 新增 tab「一级代理商家」+「货源商品」tab 改名；
  开通/取消走 `POST /admin/distributors/{merchantId}/enable|disable`；
  货源商品新建弹窗新增**必选**「一级代理商家」选择器，提交 `distributorMerchantId`（编辑只改内容不改归属）。
- API：`distributorAdminApi.enable/disable`；`MerchantItem.isDistributor`；`DistributorProductItem.distributorMerchantId/Name`；
  `DistributorProductCreatePayload.distributorMerchantId`(必填)。mapper 归一化 isDistributor。
- 命名区分：侧栏「一级代理」菜单(individual-leaders)实为**个体负责人**，与此处商家 is_distributor 不是一回事。

### C. 提现审核类型
- `enums.ts`：WITHDRAWAL_TYPE 增 `property_manager` + label + options，RoleWithdrawalApproval 筛选自动生效。

### D. 物业经理工作台（住户端，新增）
- `src/views/property-manager/`：Overview / Leaders / Earnings / Wallet 四页，参照 building-leader 系列。
- API `propertyManagerPortalApi`：my / buildingLeaders / appointBuildingLeader / earnings / wallet / createWithdrawal / withdrawals。
- 入口判定：`/auth/profile` **无** isPropertyManager 字段，故 `auth.probePropertyManager()` 调 `GET /property-managers/my`
  （非经理 91005 / 已停用 91007）置 isPropertyManager；AppLayout onMounted 对 role=resident 触发一次；
  roles.ts getMenusForRole/Profile 按 isPropertyManager 注入 propertyManagerMenus（路由 `/property-manager/*`，roles=[RESIDENT]）。
